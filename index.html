What the launcher does

The current project includes instance management, content tools and per-instance settings.

Separate instances

Keep worlds, mods and settings in separate game folders. Import and export your setups.

Versions & loaders

Choose an exact Minecraft or loader version. Use Vanilla, Fabric, Quilt, Forge or NeoForge.

Mods, packs & shaders

Browse Modrinth, add local content, or import a CurseForge pack from a ZIP or folder.

Java, RAM & logs

Set a Java runtime and RAM limits per instance. Open logs and game files from the same place.
